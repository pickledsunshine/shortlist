# Shortlist

Shortlist is an AI-powered job-search prototype that helps candidates define their ideal roles, upload a CV, and view prioritised job matches in one place. Built with Next.js, React, TypeScript, and Tailwind CSS, it is designed to reduce the repetitive work of searching and tailoring applications.

## Demo

The current version is a self-contained front-end demo. CV selection and job-search criteria are stored in the browser, and the jobs feed uses example matches. No account, database, or API key is required.

## Run locally

On Windows, double-click `Start-Shortlist.bat`, then open [http://localhost:3000](http://localhost:3000).

Or run:

```bash
npm.cmd run dev
```
